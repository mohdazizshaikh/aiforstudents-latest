Two Switches — Paper Circuit / दो स्विच का कागज़ी परिपथ

Conceptual series path only: no real wires or electricity. / केवल चित्र बनाएँ; असली बिजली या तार नहीं।

Group / समूह: ___________________   Date (optional) / तिथि: __________

Think, draw and explain / सोचें, बनाएं और समझाएं

  1. Draw one simple path with a source, switch A, switch B and a model lamp.
    स्रोत, स्विच A, स्विच B और बल्ब वाला एक रास्ता बनाइए।
  2. Draw the four A/B open or closed combinations. Circle the setup where the model lamp is ON.
    A/B के खुले या बंद होने की चार स्थितियाँ बनाएँ। जिस स्थिति में बल्ब जले, उसे घेरें।
  3. Explain what happens when either switch is open. Use the word “path.”
    बताइए कोई एक स्विच खुला हो तो क्या होता है। “रास्ता” शब्द इस्तेमाल करें।
Use pencil and paper. No personal details need to be submitted online. / केवल पेंसिल और कागज़ का प्रयोग करें। ऑनलाइन कोई निजी जानकारी देने की ज़रूरत नहीं।

Teacher-only guidance (not printed) / केवल शिक्षक के लिए

Only A closed and B closed makes the idealized series-path model lamp ON. This is not a hardware safety experiment.

Content is an original unreviewed prototype. Teachers must check age/curriculum suitability.
