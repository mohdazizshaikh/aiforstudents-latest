# M17 Teacher-Led Smart Classroom Pilot — Proposed Plan

**Status:** FIRST TEACHER-KIT CODE PILOT IMPLEMENTED (2026-11-23); **no school, teacher, learner or pilot participant recruited**. A future pilot must satisfy applicable institutional, child privacy and safeguarding requirements.

## Purpose
Adapt useful smart-classroom teaching practices to Indian schools without assuming individual laptops. Demonstrate a lesson on **one teacher laptop/projector or a shared mobile device**; make interaction, peer reasoning and offline follow-through more valuable than screen time.

## Teacher session prototype (about 15–20 minutes, to be validated)
| Phase | Teacher action | Learner action | Data collection |
|---|---|---|---|
| Prepare | Select a reviewed M15 lesson; show learning goal | Listen/read accessible description | No account needed |
| Predict | Present a real-world question with two plausible outcomes | Discuss in pairs or small groups | No student roster |
| Explore | Run M16 simulation or existing meaningful game on the shared screen | Groups take turns describing a step | No identity stored by platform |
| Explain | Use verified concept explanation and compare strategies | Say why a solution works or failed | Optional anonymous classroom tally only with review |
| Apply | Offer original printable worksheet or a low-cost home activity | Solve on paper, discuss outcome | Paper-based teacher choice; not uploaded to platform |
| Reflect | Summarize one new concept and an optional retry | Give nonjudgmental feedback | No mandatory survey |

No public leaderboard, named team rank, strangers, uncontrolled chat, image uploads, individualized public performance profiles or forced exercise streaks.

## Teacher Kit deliverables
- Original lesson facilitator card with concept, prerequisites, estimated activity duration and accessible nonvisual script.
- Projector-friendly layout: legible typography, high contrast, large button targets, no autoplay audio and no motion-only instructions.
- Shared-phone roles: handoff, listen, verify, reconsider, not one dominant player answering everything.
- Print-friendly original activity, answer explanation, material list, differentiated support suggestions and safety warnings.
- Offline alternative for students with unreliable data or no phone.
- Attribution and licensing statement for any resource link; original sheet is not an NCERT page scan.

## Teacher feedback pilot: questions, not measurements to invent
- Can a teacher start the lesson with one available device?
- Were instructions clear in the language actually spoken?
- Could learners explain **why** an answer works, rather than just guess?
- Could a child with a visual/motor/reading support need participate?
- Was the content culturally relevant and age-appropriate?
- Was the lesson accessible with a weak network and an ordinary phone?
- Did anyone feel publicly ranked, shamed or coerced?

## Go/no-go before real classroom use
1. Educator-reviewed content, accurate translations and clearly labelled official links.
2. School authorization and any appropriate consent/assent or ethical review for interaction/research.
3. Child-safety/legal and privacy check for any survey or record; avoid recording individual child data.
4. Live staging test, app accessibility review, teacher instructions and incident point of contact.
5. Human oversight. Teacher remains responsible for instruction and safe physical experiments.

## Deliverable acceptance for M17
One reviewed teacher lesson with a projector mode, printable activity, accessibility alternatives, offline fallback and documented teacher feedback from an ethical pilot **if one occurs**. The pilot is not counted complete merely by publishing a PDF or JavaScript button.
