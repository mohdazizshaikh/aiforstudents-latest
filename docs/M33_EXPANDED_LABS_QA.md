## Privacy and offline engineering
Dedicated transient storage-only reset signal supplements BroadcastChannel. Removing the ordinary remembered-history key when disabling remember must not erase another tab's in-memory session. Explicit clear propagates without personal data even in fallback contexts, resets new draft lab state and removes the signal. This is not a guarantee across other browsers/devices. Worker cache now explicitly includes the previously missing teacher-cards engine dependency; offline tests open the actual card page, verify Hindi and print exclusion, and exercise expanded labs and practice hints. Local Chromium only, not actual low-end Android, screen reader or printer testing.
