# M32 B1 — Optional Practice Guide, reused fraction journey, teacher navigation and print cards

**Date:** 2026-11-24. **Status:** Code/testing prototype ONLY. **B1:** 46/50 source-and-test-scoped tasks; exactly 4 need real external subject/Hindi reviewer evidence. **B2:** not started in this checkpoint. **Public child launch:** NOT APPROVED.

## Actual new working code

**Local Practice Guide (`/#local-learning-guide`).** Original fixed-topic, click-only draft hints from existing Science, Maths Workshop and Studio source modules. Twelve predefined source topics, Hindi/English choices, explicit source attribution and review status `UNREVIEWED_ORIGINAL_DRAFT`; unknown topics lead to a truthful abstention, not a hallucinated answer. A separate fixed “trusted adult” option gives non-diagnostic, age-appropriate safety guidance. **No open text box, generative LLM, chat history, cloud inference, storage or tracking**; this is **NOT an implemented AI tutor**. Whether any content is appropriate for children remains a qualified human decision.

**Local optional practice chooser.** Learner explicitly selects subject (Maths, Physics, Chemistry, Biology or Digital Safety), `gentle/standard/explore` difficulty and an independent language override. This generates a **declinable** short practice link with explainable reasons, not ability or intelligence inference. Repeating after +1/+3/+7 days is offered only as an **optional paper date**, with no automatic reminders, penalties, streak or score. All guide state remains memory-only and resets on application privacy clear.

**Five-stage fraction shell.** A learner-facing Learn → Try → Play → Understand → Grow shell now reuses the **original M15 Studio fractions draft**, including an accessible 0–4 shading counter, exact 2/4 = 1/2 reference and numerical feedback. It is deliberately **not a new approved, chapter-verified Maths lesson** and no new educational question records are counted.

**Teacher navigation.** Teacher projector view retains large controls and now has an accessible Jump to Step selector for both original lesson plans. Each next step advances a **generic, anonymous** classroom role; no child rosters, names, attendance or answers are collected. `/teacher-kit/cards/` is a new, original, local A4 learner discussion card page displaying teacher guidance on screen only; **print CSS always hides teacher answers**. Cards are derived from existing 10 unreviewed teacher steps, not 10 new approved lessons.

## Engineering acceptance (NOT human evidence)

- Pure reference functions test optional day gaps across leap-year dates, absence of mastery/diagnostic judgement and every fraction shading state.

- Browser checks cover keyboard-enter fraction controls, overrideable Hindi advice, decline and clear-date flows, trusted-adult fallback, teacher step jump, actual learner-card page, A4 print media hiding teacher answers, offline bootstrapping and no runtime errors.
- Worker cache `aifs-discovery-m32-2026-11-24`; source-backed private Hostinger staging archive `aiforstudents_hostinger_staging_m32.zip`. **Artifact is not a live deployment.**
- All existing **3,292** educational draft review records (original 3,282 + M30 Maths 3 + M31 Science 7) still require qualified teachers/Hindi reviewers. No new distinct educational task record is created by exposing existing source hints/cards.
- Strict CI CSP/noindex, offline source parity, nonpublic sensitive paths and intentionally failing public release preflight remain required.
