# M62 — Printable teacher demonstration sequence

Extends the existing memory-only eight-model agenda with a bilingual print preview in the same document. Source titles, prompts and caveats in agenda order; no teacher hints, answers, names, roster, scores or URLs. Native printing isolates preview from other application sections and controls. Close, agenda changes, language changes and shared-device reset discard preview; printouts cannot be remotely erased. Physical A4 testing and educator/rights signoff remain pending. Not full teacher administration, no backend. CI required.
