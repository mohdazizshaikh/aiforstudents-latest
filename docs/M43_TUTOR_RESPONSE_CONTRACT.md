This candidate extends the existing M35 empty approved-source gate with a deterministic response schema and exact-excerpt test harness. It does not connect a model, implement a chatbot, approve source data or generate responses.

Production-facing checkDisabledTutorResponse accepts only the existing fixed ID/hash/language request shape and returns an unavailable, null answer and citation for every valid request. The trusted registry remains empty. Synthetic contract tests use fixed non-educational English/Hindi tokens only: exact request binding, source version, passage ID, digest, exact excerpt, bounded length and no extra fields. The synthetic verifier returns only a contract match flag; it is separate from the production gate and cannot populate the registry. Even a matching synthetic response is denied by the production gate.

Test coverage includes extra fields (including fake approval or child data), malformed requests, stale source versions, language mismatches, forged citations, unsupported added claims and excessive length. This is structural validation, not semantic correctness, prompt-injection resilience, bias evaluation, actual model red-teaming or safety certification.
