Privacy by default — prototype

This prelaunch practice prototype does not require accounts or ask for names, schools, phone numbers or addresses. The games are bundled with the website; there is no remote AI call, analytics SDK, advertising pixel or student social-chat service.

Game attempts, selected age band, reflections and optionally self-reported exploration missions are processed in your browser. By default, tab-session storage may hold that activity for the current tab session. If you select Remember my progress, the app saves it on this browser using local storage. Data may be available to other people using this browser and may be lost if browser data is cleared. Do not use a shared public device for private reflections.

Clear local history removes this app's known progress keys from the current browser. It cannot erase copies you manually exported, other browsers/devices, browser backups or history already visible to someone using the device. Disabling the storage preference is not an automatic delete; use the clear button to remove data.

Other open tabs: In browsers with supported same-origin messaging, clearing history sends a local, data-free reset signal to other open tabs from this site in the same browser profile. No answers, names or personal records are sent in that signal. This does not reach different browser profiles or devices, tabs that are not running, browser backups or manually copied records. On a shared device, clear history and close the site in every tab after use.
